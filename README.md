## Project Overview

This repository contains my coursework for WDD 331R Advanced CSS at BYU–Idaho.

The purpose of this portfolio is to demonstrate my understanding of CSS architecture, responsive design, custom properties, reusable components, and modern CSS techniques.

In Unit 3, I added a tokenized color system, implemented Light Mode, Dark Mode, and System Mode, and created a Visual Effects Showcase using shadows, gradients, and filters.

## Folder Structure

- `index.html` — Main portfolio homepage.
- `css/main.css` — Main CSS file that imports the project's stylesheets.
- `css/tokens/colors.css` — Contains color seeds, accent ramps, semantic color tokens, and theme switching rules.
- `css/tokens/variables.css` — Contains design tokens for spacing, typography, radii, transitions, icons, and shadows.
- `css/base/` — Contains CSS resets and default HTML element styles.
- `css/layout/` — Contains responsive page layouts and grid styles.
- `css/components/` — Contains reusable CSS components such as cards, the theme toggle, and visual effects.
- `css/components/theme-toggle.css` — Contains styles for the theme selection controls.
- `css/components/effects.css` — Contains styles for shadows, gradients, filters, frosted glass, and icons.
- `css/utilities/` — Contains utility styles, including the visually-hidden class.
- `js/theme-preference.js` — Saves and restores the user's selected theme.
- `unit-1/` — Contains Unit 1 coursework.
- `unit-2/` — Contains Unit 2 coursework.
- `unit-3/visual-effects/` — Contains the Visual Effects Showcase page.
- `dist/styles.css` — Bundled and minified CSS generated by Lightning CSS.

## CSS Architecture

This project uses CSS cascade layers in the following order:

`tokens → base → layout → components → utilities`

The layers help organize CSS by responsibility and make the styles easier to maintain.

## Unit 3: Tokenized Color System and Dark Mode

For Unit 3, I updated my portfolio to use modern CSS color techniques and support different appearance preferences.

### Color Tokens

The color system is located in `css/tokens/colors.css`.

I used the following CSS features:

- `oklch()` — Defines my primary accent color using lightness, chroma, and hue.
- `color-mix()` — Generates lighter and darker variations of my accent color.
- `light-dark()` — Provides different color values depending on the selected appearance.
- CSS custom properties — Allow colors to be reused throughout the website.

Some of my semantic color tokens include:

- `--color-bg`
- `--color-surface`
- `--color-text`
- `--color-accent`
- `--color-link`
- `--color-border`

These tokens make the website easier to maintain because I can change colors in one place instead of updating every component individually.

### Theme Switching

My portfolio supports three appearance options:

- **Light Mode** — Displays the light color palette.
- **Dark Mode** — Displays the dark color palette.
- **System Mode** — Follows the user's operating system appearance settings.

The theme toggle is styled in `css/components/theme-toggle.css`.

JavaScript in `js/theme-preference.js` uses `localStorage` to remember the user's selected theme after refreshing the page.

I also included keyboard navigation and visually hidden labels to improve accessibility.

### Responsive Design

The portfolio uses CSS Grid and Flexbox to adapt to different screen sizes.

I tested the homepage in both desktop and mobile views to make sure the navigation, cards, and theme toggle remain usable.

## Unit 3: Visual Effects

For this assignment, I created a page where I practiced using different CSS visual effects.

I learned how to use shadows, gradients, filters, and positioning to improve the appearance of my website.

The page is located in `unit-3/visual-effects/index.html`, and the CSS is located in `css/components/effects.css`.

### Shadows and Gradients

I learned the difference between `box-shadow`, `text-shadow`, and `drop-shadow()`.

- **Box Shadow** — Used for my cards when hovering.
- **Text Shadow** — Used to make text easier to read over images.
- **Drop Shadow** — Used to create shadows around my SVG icons.

I also used `linear-gradient()` to create an overlay on my hero image.

This helped me understand how gradients can make text easier to read while keeping the background image visible.

### Card Effects

I created three cards with different effects:

- **Layered Shadows** — Added shadows when hovering over cards.
- **Gradient Surfaces** — Used `linear-gradient()` to create a colorful background.
- **Filtered Images** — Used `grayscale()` to change an image when hovering.

I also practiced using `position: relative`, `position: absolute`, and `z-index` to place text over images.

This helped me better understand how elements can be positioned and layered on a webpage.

### Frosted Glass

I created a frosted glass effect using `backdrop-filter`.

I used the following CSS properties:

- `blur()` — Blurs the background behind the panel.
- `saturate()` — Adjusts the background colors.
- `light-dark()` — Changes the panel background depending on the theme.
- `border-radius` — Adds rounded corners.

I also included a `prefers-reduced-motion` media query to provide a solid background instead of the blur effect.

This helped me understand how CSS can create visual effects while also considering accessibility.

### Icon Shadows

I created a row of SVG icons using Flexbox.

I learned that `drop-shadow()` follows the actual shape of an image, while `box-shadow` creates a shadow around its rectangular box.

I also practiced stacking multiple `drop-shadow()` filters and using `currentColor`.

This helped me understand how different types of shadows work and when to use them.

### Light and Dark Mode Testing

I tested my visual effects in both light and dark mode.

This helped me understand how CSS custom properties and `light-dark()` work together to change the appearance of my website.

I also learned the importance of checking whether text, shadows, and other effects remain visible when changing themes.

### What I Learned

This assignment helped me understand:

- How to create different types of shadows.
- How gradients improve text readability.
- How to position text over images.
- How filters and transitions work.
- How to create frosted glass effects.
- How to use CSS variables to keep my styles organized.
- Why testing light and dark mode is important.

## Build Tool

I chose Lightning CSS to bundle and minify my stylesheets.

Lightning CSS combines the imported CSS files into a single optimized stylesheet.

### How to Run the Build

First, install the project dependencies:

```bash
npm install
```

Then run:

```bash
npm run build
```

This executes the following command:

```bash
lightningcss --bundle --minify css/main.css -o dist/styles.css
```

The generated file is saved at `dist/styles.css`.
