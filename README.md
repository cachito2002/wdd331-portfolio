## Unit 4: CSS Grid and Responsive Layouts

In Unit 4, I created two responsive layouts using CSS Grid and Flexbox.

The goal was to make the pages adjust automatically to different screen sizes.

### Editorial Layout

I created a page with a main article and a sidebar.

I used:

- `display: grid` — Creates a Grid layout.
- `grid-template-areas` — Gives names to different sections.
- `grid-area` — Places elements in those sections.
- `grid-template-columns` — Controls the column widths.
- `gap` — Adds spacing between sections.
- `@media` — Changes the layout based on screen width.

On mobile screens, the article appears above the sidebar.

On desktop screens, the article and sidebar appear next to each other.

I also used Flexbox to arrange the navigation links.

### Responsive Cards

I created six cards that automatically change their arrangement depending on the screen size.

I used:

- `repeat()` — Repeats the column pattern.
- `auto-fit` — Fits as many columns as possible.
- `minmax()` — Controls minimum and maximum column widths.
- `min()` — Prevents the columns from becoming wider than their container.
- `1fr` — Allows columns to grow equally.

My Grid uses:

    grid-template-columns: repeat(auto-fit, minmax(min(240px, 100%), 1fr));

This allows the cards to display in one, two, or three columns depending on the available space.

### Flexbox and Card Alignment

I used Flexbox to place the image placeholder above the text.

I also wanted the **Read more** links to stay at the bottom of each card.

To do this, I used:

- `display: flex` — Activates Flexbox.
- `flex-direction: column` — Arranges elements vertically.
- `flex: 1` — Makes the content area grow.
- `margin-block-start: auto` — Pushes the link to the bottom.
- `flex-shrink: 0` — Keeps the placeholder at its fixed height.

I chose this approach because the links stay aligned even when the cards have different amounts of text.

### Logical Properties

For my choose topic, I studied Logical Properties.

I used:

- `padding-block` — Adds spacing in the block direction.
- `padding-inline` — Adds spacing in the inline direction.
- `margin-block-start` — Adds space before an element in the block direction.
- `margin-block-end` — Adds space after an element in the block direction.

These properties make layouts more flexible when the writing direction changes.

### Responsive Testing

I tested both pages at different screen widths.

The Editorial Layout changes from one column to two columns.

The Responsive Cards page changes between one, two, and three columns.

I also checked that the cards fit the screen and that the Read more links stay aligned.

- How named Grid areas work.
- How to create responsive columns automatically.

## Build Tool

I used Lightning CSS to bundle and minify my stylesheets.

This tool combines my CSS files into one optimized file.

### How to Run the Build

First, install the dependencies:

    npm install

Then run:

    npm run build

The build uses this command:

    lightningcss --bundle --minify css/main.css -o dist/styles.css

The generated CSS is saved in `dist/styles.css`.
